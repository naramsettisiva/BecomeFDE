# Learning Log

One entry per day. Write it at the end of the day, before you commit.

This file is not a diary — it is **source material for your curriculum**. Every
line under "What confused me" is a place a future student will get stuck. On
Day 22 you will mine this file to build your lesson plan. The specificity of
your teaching four weeks from now is set by the honesty of these entries today.

---

## Template

```
## Day NN — <date> — <topic>

**Shipped:** <the artifact, one line>

**What confused me:**
- <the specific thing, not "embeddings were hard" but "I assumed cosine
  similarity was normalised and it wasn't, so my top-k was garbage">

**What I'd tell a student to avoid:**
- <the trap, phrased as advice>

**Question I could not answer:**
- <the thing you'd have to look up if a student asked it live>

**Teach-back recording:** teaching/recordings/day_NN.mov — <self-grade 1-5>
**Time actually spent:** <hh:mm>   **Cost today:** $<x.xx>
```
